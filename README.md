## About Cabinet Designer

Cabinet Designer consolidates cabinet planning, layout work, and fabrication preparation into one web interface. Woodworkers can assemble designs, check proportions in 3D, and carry a concept through to shop-ready files without jumping between separate applications.

Both professional shops and hobby workflows benefit when accurate parts, clear material assignments, and exportable output are important. A parametric approach makes iterative design practical, and the preview and reporting tools let you examine the build before it goes to production or gets shared with others.

---

## Features

- Build cabinet assemblies in 2D and 3D
- Inspect models through a real-time 3D preview
- Draw on a material and hardware library covering common build components
- Create cut lists automatically from the active design
- Optimize panel layouts and nesting for more efficient material use
- Send results to Excel and PDF for documentation and planning
- Generate CNC router toolpaths and G-code for fabrication
- Export SCM Maestro-compatible files for downstream production

## Usage

1. Start a new cabinet project or load an existing one.
2. Set the cabinet dimensions, panels, and hardware.
3. Examine the assembly in 2D, then switch to the 3D preview to inspect the model.
4. Generate the cut list and export it to Excel or PDF.
5. Run the nesting tools to review layout efficiency.
6. Export CNC-related output such as toolpaths, G-code, STEP, or SCM Maestro formats when needed.

A typical workflow:

- Sketch the cabinet structure
- Refine the parametric values
- Check the rendered result
- Export documentation and machine-ready data

## FAQ

**Where can I find the newest release?**

Yes. The application ships with a library of cabinet-related parts and components.
